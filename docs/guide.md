# Справка

Руководство пользователя: запуск, работа с интерфейсом, параметры, загрузка территории, экспорт и API.

## Установка и запуск

Требуется Python 3.11 или новее. Основные зависимости: NumPy, SciPy, pandas, GeoPandas, Shapely, Rasterio, pyproj, NetworkX, FastAPI, Pillow.

```bash
git clone https://github.com/DmitryLeLeE/eco_corridor
cd eco_corridor
python -m venv .venv && source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -e .                                          # для тестов: pip install -e ".[dev]"
ecocorridor --port 8000
```

Откройте <http://127.0.0.1:8000>. Демонстрационный полигон «Синий Бор» (синтетический, 60 × 45 км, ячейка 100 м) доступен сразу. Rasterio и GeoPandas на Windows проще ставить из готовых колёс (`pip install` их подтягивает) или через conda-forge.

Проверка установки: `python -m pytest -q` — 86 тестов должны пройти.

**Windows без установки Python.** На странице [Releases](https://github.com/DmitryLeLeE/eco_corridor/releases) лежит архив `ecocorridor-<версия>-windows-x64.zip`: распакуйте и запустите `ecocorridor.exe`. Откроется окно консоли (его нельзя закрывать, пока вы работаете) и браузер с приложением. Онлайн-загрузка территорий идёт через интернет, кэш хранится в `%USERPROFILE%\.cache\ecocorridor`. Приложение не подписано цифровой подписью, поэтому Windows SmartScreen может показать предупреждение («Подробнее» → «Выполнить в любом случае»).

## Интерфейс

**Верхняя панель.** Название и размер проекта; кнопки «Территория» (загрузка данных), «Методика» (краткая справка в приложении), «Сценарии» (сравнительная таблица), «Пересчитать».

**Левая панель.**

* *Сценарий* — базовый, урбанизация, новая автодорога, восстановление пойм.
* *Поверхность сопротивления* — веса рельефа, дорог и застройки; способ композиции.
* *Коридорная сеть* — тип местообитания, соседство ячеек (8 или 16), максимальная длина связи, ширина коридора, допуск альтернатив, дальность расселения d₀.
* *Данные* (только для загруженных территорий) — источники, предупреждения о качестве данных.
* *Слои карты* — сопротивление, землепокров, доступность, рельеф, дороги и реки, подписи.

**Карта.** Колесо мыши — масштаб, перетаскивание — сдвиг. Клавиши: `F` — вся территория, `R` — режим маршрута, `Esc` — отмена. Подсказка при наведении показывает ядро, коридор или узкое место; в строке под картой — координаты и сопротивление под курсором.

**Правая панель.** Показатели MESH, PC, IIC и число связей (с изменением относительно базового сценария), статистика сети, список коридоров и узких мест, структура патчей.

## Параметры

| Параметр | Что делает | В интерфейсе / допустимо в API | По умолчанию |
|---|---|---|---|
| Рельеф, w<sub>s</sub> | Вес поправки за уклон | 0–2 / 0–3 | 0,9 |
| Дороги, w<sub>r</sub> | Вес влияния близости дорог | 0–2 / 0–3 | 0,8 |
| Застройка, w<sub>u</sub> | Вес влияния близости застройки | 0–2 / 0–3 | 0,6 |
| Затухание дорог D<sub>r</sub> | Расстояние, на котором влияние дороги падает в e раз | — / 50–3000 м | 350 м |
| Затухание застройки D<sub>u</sub> | То же для застройки | — / 100–8000 м | 1200 м |
| Опорный уклон | Уклон, при котором поправка за рельеф достигает максимума | — / 5–60° | 22° |
| Композиция | Мультипликативная или взвешенная сумма | 2 варианта | мультипликативная |
| Местообитание | Какие классы считаются местообитанием для индексов | natural / forest / forest_wetland | natural |
| Соседство | 8 или 16 направлений в графе | 8 / 16 | 8 |
| Максимальная связь | Предельное расстояние между ядрами для кандидатов в связи | 5–80 км / 1–120 | 34 км |
| Ширина коридора | Ширина полосы вокруг оси | 100–1000 м / 50–2000 | 250 м |
| Допуск альтернатив | Во сколько раз альтернативная связь может быть дороже пути по остову | 1–2 / 1–3 | 1,25 |
| Ядро расселения d₀ | Масштаб вероятности расселения для PC и IIC | 1–20 км / 0,5–50 | 5 км |
| Минимальная площадь патча | Патчи меньше исключаются из PC / IIC | — / 0,5–200 га | 5 га |

**Как выбирать значения.** Веса и затухания — это экспертные допущения, а не измеренные величины: меняйте их, чтобы *проверить устойчивость вывода*, а не чтобы «подогнать» красивую карту. d₀ должен соответствовать способности расселения выбранного вида; значение по умолчанию (5 км) — условное. Подробности — в разделе [«Методика»](methodology.html).

## Сценарии

| Сценарий | Что меняется | Влияет на |
|---|---|---|
| Базовый | Текущее состояние | — |
| Урбанизация +600 м | Вокруг существующей застройки (кроме воды) в радиусе 600 м земля становится застроенной: сопротивление не ниже 250, местообитание исчезает | MESH, PC, IIC, коридоры |
| Новая автодорога | Полоса 60 м (для демо — по заданным координатам, для загруженных территорий — по кратчайшей линии между двумя крупнейшими ядрами) становится дорогой: сопротивление не ниже 400, местообитание разрезается | MESH, PC, IIC, коридоры |
| Восстановление пойм | В полосе 500 м от воды (за пределами застройки) сопротивление умножается на (1 − 0,55); луга, пойменные земли и редколесье учитываются как местообитание | сопротивление и стоимость коридоров; PC и IIC — только если появляется новое местообитание |

Сценарии иллюстративны. Они не заменяют проектных вариантов и не оценивают вероятность реализации.

## Загрузка территории

1. Нажмите **«Территория»**, введите название места или откройте «или задать центр координатами».
2. Выберите найденный объект. Размер кадра подставится из размера объекта (не меньше 20 км и не больше ~122 км по стороне); при необходимости измените.
3. Выберите разрешение (по умолчанию подбирается автоматически, целевое ~300 тыс. ячеек), источник ядер и минимальную площадь ядра.
4. Нажмите **«Загрузить и рассчитать»**. Ход загрузки показывается индикатором; одновременно выполняется одна загрузка.
5. Загруженные территории сохраняются в `data/cache/` и доступны в списке «Уже загружено». Флажок «игнорировать кэш» запускает загрузку заново.

**Источник ядер.**

* *ООПТ, иначе крупные леса* (по умолчанию): охраняемые территории из OpenStreetMap; если их меньше двух, берутся крупнейшие лесные массивы WorldCover (с предупреждением).
* *Только ООПТ из OSM*: если найдено меньше двух, сеть коридоров не строится (с предупреждением).
* *Крупные массивы леса / природных земель*: ядра определяются по землепокрову.

**Что делать, если загрузка не удалась.**

| Сообщение | Причина и действие |
|---|---|
| «Сервис геокодирования недоступен» | Нет доступа к nominatim.openstreetmap.org или превышен лимит запросов; повторите позже или задайте координаты |
| Ошибка Overpass / «remark» | Публичный сервер перегружен; приложение пробует зеркала, затем сообщает об ошибке — повторите позже |
| «Не удалось открыть ни одного тайла WorldCover» | Нет доступа к AWS или неверный адрес; проверьте сеть и переменные `ECOCORRIDOR_*` |
| Предупреждение о плоском рельефе | Тайлы Copernicus DEM недоступны: уклон принят равным нулю, результаты по рельефу недостоверны |
| «Найдено меньше двух ядер» | В кадре мало ООПТ: увеличьте кадр, уменьшите минимальную площадь ядра или выберите источник «леса» |
| Уже идёт загрузка (409) | Дождитесь завершения текущей |

## Экспорт

* **Отчёт** (HTML, самодостаточный): карта, показатели, таблица коридоров, методика. Версия программы и параметры указаны в отчёте.
* **GeoJSON** — оси коридоров в проекции проекта (UTM; CRS указан в файле), с атрибутами длины, стоимости, типа связи.
* **CSV** — таблица показателей выбранного сценария.

## Как интерпретировать результаты

* Сравнивайте **сценарии между собой при одних и тех же параметрах**; не сравнивайте абсолютные значения PC между разными территориями или разными разрешениями.
* PC, IIC и MESH зависят от **выбора местообитания** и **ядра расселения d₀**; изменение этих параметров меняет и значения, и выводы.
* «**Узкие места**» — эвристика (поток / локальная ширина). Это места для полевой проверки, а не доказанные точки уязвимости.
* Положение отдельных коридоров **чувствительно к сопротивлениям** ([Валидация](validation.html)); опирайтесь на устойчивые черты (какие ядра связаны, где коридор неизбежно проходит через барьер), а не на конкретную трассу.
* Качество входных данных — предел точности вывода ([Данные](data.html)).

## Программный интерфейс (HTTP API)

| Метод и путь | Назначение |
|---|---|
| `GET /api/project?project_id=` | Описание проекта: границы, классы, слои, сценарии, предупреждения |
| `GET /api/projects` | Демо и загруженные территории |
| `POST /api/analyze` | Расчёт сценария: `{project_id, scenario, params}` |
| `POST /api/compare` | Сравнение сценариев |
| `GET /api/layers/{token}/{layer}.png` | Растровые слои: hillshade, landcover, resistance, cost |
| `POST /api/route`, `GET /api/sample/{token}` | Маршрут наименьшей стоимости; значение сопротивления в точке |
| `GET /api/export/{token}/report.html`, `corridors.geojson`, `metrics.csv` | Экспорт |
| `GET /api/territory/search?q=` | Поиск территории (Nominatim) |
| `POST /api/territory/plan` | Рассчитать кадр и разрешение, не скачивая данные |
| `POST /api/territory/load` → `GET /api/territory/jobs/{id}` | Фоновая загрузка и опрос прогресса |

Интерактивная документация FastAPI: `/docs` на запущенном сервере. Токен результата — детерминированная функция проекта, сценария и параметров ([Воспроизводимость](reproducibility.html)).

## Переменные окружения

| Переменная | Назначение |
|---|---|
| `ECOCORRIDOR_CACHE` | Каталог кэша загруженных территорий (по умолчанию `data/cache`) |
| `ECOCORRIDOR_NOMINATIM` | Адрес геокодера |
| `ECOCORRIDOR_OVERPASS` | Список серверов Overpass через запятую |
| `ECOCORRIDOR_WORLDCOVER_URL`, `ECOCORRIDOR_COPDEM30_URL`, `ECOCORRIDOR_COPDEM90_URL` | Шаблоны адресов тайлов с `{tile}` |

## Статическая версия на этом сайте

[Демо](demo/index.html) показывает результаты демонстрационного полигона для четырёх сценариев при параметрах по умолчанию. Параметры, маршруты и загрузка территорий там отключены: для них нужен запущенный сервер. Файлы данных демо лежат в `demo/data/`; в [`provenance.json`](provenance.json) записаны версии пакетов и токены расчётов.
