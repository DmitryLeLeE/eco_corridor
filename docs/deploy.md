# Размещение на сервере

Статическая версия на GitHub Pages не может считать: у неё нет серверной части. Полноценное приложение (расчёт на лету, онлайн-загрузка территорий, свои данные) нужно разместить как обычный веб-сервис. Образ собирается из `Dockerfile` в корне репозитория.

## Что понадобится от сервера

* **Память.** Расчёт загруженной территории (около 300 тыс. ячеек) занимает 1–2 ГБ; слой «Ток» (теория цепей) на 270 тыс. ячеек — около 1 ГБ сверх этого. На бесплатных тарифах с 512 МБ крупные территории не поместятся: используйте грубое разрешение или демо.
* **Исходящий доступ в интернет** к `nominatim.openstreetmap.org`, `overpass-api.de` (и зеркалам), `esa-worldcover.s3.eu-central-1.amazonaws.com`, `copernicus-dem-30m.s3.eu-central-1.amazonaws.com`. Без него работают демо и «свои данные».
* **Диск** для кэша территорий (`ECOCORRIDOR_CACHE`, по умолчанию `/data/cache`). Без постоянного диска кэш пропадает при перезапуске, территория загрузится заново.

## Запуск образа

```bash
docker run -p 8000:8000 -v ecocorridor-data:/data ghcr.io/dmitrylelee/ecocorridor:latest
```

Образ публикуется в ghcr.io при выпуске версии (тег `v*`). Порт задаётся переменной `PORT` (по умолчанию 8000); контейнер работает не от root.

## Переменные окружения для публичного сервера

| Переменная | Назначение |
|---|---|
| `PORT` | порт HTTP |
| `ECOCORRIDOR_CACHE` | каталог кэша территорий |
| `ECOCORRIDOR_MAX_UPLOAD_MB` | предел размера ZIP со своими данными (по умолчанию 400) |
| `ECOCORRIDOR_DISABLE_IMPORT` | любое значение отключает загрузку своих данных |

## Площадки

**Render.** В репозитории есть `render.yaml`: *New → Blueprint → выберите репозиторий*. Бесплатный план засыпает при простое и не имеет постоянного диска.

**Hugging Face Spaces (Docker).** Создайте Space типа Docker, добавьте в начало `README.md` Space заголовок `sdk: docker` и `app_port: 8000`, загрузите содержимое репозитория. Пространство работает от пользователя с uid 1000, как и образ.

**Свой сервер.** `docker run` выше за обратным прокси (nginx, Caddy) с HTTPS.

## Что нужно знать перед публикацией

* **Нет аутентификации и ограничений нагрузки.** Любой посетитель может запустить расчёт и загрузку территории (загрузка идёт по одной, остальные получают отказ 409). Для открытого доступа поставьте перед сервисом ограничение частоты запросов или закройте его паролем на уровне прокси.
* Приложение обращается к публичным сервисам OpenStreetMap от имени сервера: соблюдайте их [политики использования](https://operations.osmfoundation.org/policies/nominatim/) и не открывайте массовую загрузку.
* Результаты расчётов хранятся в памяти процесса (последние шесть); несколько воркеров не разделяют их. Запускайте **один** процесс.
* Эти образ и конфигурация проверены только сборкой в CI и пробным расчётом демо; нагрузочного тестирования не проводилось.
