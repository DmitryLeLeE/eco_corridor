Как считается связность

EcoCorridor строит относительную модель связности: от поверхности сопротивления через наименьшие по стоимости пути к сети коридоров и индексам фрагментации.

1. Поверхность сопротивления

Базовая стоимость класса земного покрова умножается на поправки за уклон, дороги и застройку:

R = R_lc · (1 + w_s·s) · (1 + w_r·e^(−d_r/350)) · (1 + w_u·e^(−d_u/1200))

где s — уклон, нормированный до 22°, d — расстояние до ближайшей дороги / застройки. Стоимость перехода между соседними ячейками — d·(R_a+R_b)/2. Веса w регулируются в левой панели.

2. Least-cost path

Растр превращается в граф 8-соседства (≈2,2 млн рёбер для 60×45 км при 100 м). Кратчайшие пути — точный алгоритм Дейкстры на разреженной матрице (scipy.sparse.csgraph). Между каждой парой ядер прогоняется один multi-source Дейкстра от всех ячеек ядра.

3. Коридорная сеть

Кандидаты — пары ядер ближе заданного порога. Остов — минимальное остовное дерево по стоимости связей (NetworkX). Альтернативные коридоры добавляются, если их стоимость не превышает остовный путь более чем в 1,25 раза. Поток в ячейке — число связей, проходящих через неё.

4. Фрагментация и связность

Патчи выделяются 8-связностью на маске естественных местообитаний. Эффективный размер сети: MESH = ΣAᵢ²/A. Индексы: IIC = ΣΣ aᵢaⱼ/(1+nᵢⱼ)/A² и PC = ΣΣ aᵢaⱼ·e^(−dᵢⱼ/d₀)/A². dPC показывает вклад каждого патча в связность.

5. Узкие места

Для каждой ячейки коридора считается локальная ширина (удвоенное расстояние до края коридора). Оценка узкости — поток / ширина; локальные максимумы с потоком ≥ 1 попадают в список приоритетов.

Ограничения. Демонстрационный ландшафт «Синий Бор» синтетический (60 × 45 км, EPSG:32637), сопротивления относительны и не калиброваны по данным мечения. Модель предназначена для сравнения сценариев между собой, а не для абсолютных выводов о проницаемости.
