# Журнал изменений

## 0.2.0

* Онлайн-загрузка любой территории: поиск (Nominatim), план кадра, WorldCover 10 м, Copernicus DEM, OSM (дороги, реки, ООПТ), кэш, фоновая загрузка.
* Аудит методики (`docs/METHODOLOGY_REVIEW.md`): исправлены нормировка индексов на площадь ландшафта, учёт многозвенных путей в IIC и PC, анизотропия путей, свойства проекта в расчётах API.
* Добавлены индексы ECA и dPC; пресеты местообитаний.
* Светлая научная тема интерфейса.
* 45 автоматических тестов; анализ чувствительности (`scripts/sensitivity.py`).
* Пакет устанавливается через `pip install .`; команда `ecocorridor`; демо-данные внутри пакета (`src/ecocorridor/demo_data`); кэш по умолчанию — `data/cache` в клоне репозитория, иначе `~/.cache/ecocorridor`.
* Лицензия MIT, `CONTRIBUTING.md`, `Dockerfile`, CI на Python 3.10–3.12 со сборкой wheel, workflow публикации релиза по тегу `v*`.
* Сайт документации (GitHub Pages): справка, методика, валидация, данные, воспроизводимость, научная практика.
* Исправлены ошибки атрибуции источников (dPC, ECA; удалена ссылка, не подтверждённая первоисточником).
