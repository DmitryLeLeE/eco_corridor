# Как внести вклад

Спасибо за интерес к проекту. Ниже — минимум, который нужен, чтобы изменение было принято.

## Окружение

```bash
git clone https://github.com/DmitryLeLeE/eco_corridor && cd eco_corridor
python -m venv .venv && . .venv/bin/activate
pip install -e ".[dev]"
python -m pytest -q
```

## Правила

* Любое изменение алгоритма сопровождается тестом с заранее известным (аналитическим) ответом; число в тесте нельзя подгонять под вывод программы.
* Изменение формул или индексов требует ссылки на первоисточник в docstring и в [списке источников](docs/references.md). Ссылки сверяйте с оригиналом: неверная атрибуция считается ошибкой.
* Изменения, влияющие на числа, записывайте в `CHANGELOG.md`.
* Если вы использовали ИИ-инструменты, укажите это в описании запроса: название и версия, для чего, как проверено вами.
* Данные и результаты для реальных мест, раскрывающие местонахождение редких видов, в репозиторий не добавляйте.

## Сообщения об ошибках

Укажите версию (`ecocorridor --version`), ОС, входные данные (территория, разрешение) и текст ошибки. Для расхождений в числах приложите параметры сценария и токен результата.

## Безопасность

Приложение не рассчитано на публикацию в открытой сети без обратного прокси и ограничений: оно скачивает данные из внешних сервисов по запросу пользователя. О найденных уязвимостях сообщайте автору через GitHub Security Advisories репозитория.
